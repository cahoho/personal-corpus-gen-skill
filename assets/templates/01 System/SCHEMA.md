# 语料库结构与规则

本文件描述此语料库的实际约定。初始模板只是起点，不是任何个人事实的证据。仅在用户授权后调整约定；迁移前应比较拟议变更与现有内容，绝不静默替换用户修改。

## 位置与笔记类型

- `00 Start Here.md`：简要入口和阅读边界。
- `00 Inbox/`：未经确认、非敏感的候选内容；它们不是已确定的事实。
- `01 System/`：本规则文件以及可选的 `Templates/`。
- `02 Self/`：自我认同、可能变化的基本信息、隐私规则和协作偏好。
- `03 Topics/`、`04 Events/`、`05 Projects/`：按需创建笔记，不为分类而创建空目录。
- `06 MOCs/`：普通导航；MOC 不是其摘要内容的权威来源。
- `07 Privacy/`：经明确批准保存的必要私密记忆及其私密 MOC。它位于同一个语料库中，并非受保护的独立语料库。
- `90 Sources/`：最小必要的来源批次说明；不自动复制对话。
- `99 Archive/`：可选目录，用于保存经批准保留的材料；归档不等于删除。

使用 UTF-8 Markdown 和有效的 YAML 文档头。优先使用稳定且唯一的文件名或带路径的 Obsidian 双向链接；建立链接时说明关系和用途。Obsidian 双向链接属于扩展，阅读工具可能不会自动跟随。无需插件、数据库或特殊主题。避免失效或猜测性的链接，导出前检查标题、链接、嵌入内容和元数据是否泄露信息。

## 元数据

只使用笔记确有需要的字段。`type` 标识类型。可选的 `created` 和 `updated` 是笔记创建和修改日期，而非事件日期。`event_date` 是事件实际日期；`valid_as_of` 是整篇笔记已知的适用日期，并不证明其现在仍然有效；`last_mentioned` 是在已处理且日期已知的来源中最后一次明确提及的时间，而非所有平台上的最后提及时间。`status` 需要证据或用户确认；`aliases` 是 YAML 列表；`sensitivity` 是供人阅读的提示，不是访问控制。

未知日期和可选字段应省略，绝不编造日期。在正文中以原有精度保留不完整或大致日期。不适用于整篇笔记的日期应写在相关条目旁。仅在核实有相关提及时更新 `last_mentioned`，不能仅因处理了较晚的批次就更新。未配置提醒、阈值、定时任务或自动提醒；只在用户询问或当前请求需要时计算经过时间。未提及不是项目结束或偏好改变的证据。

## 记忆与证据

每条独立记忆都应包含内容及相关上下文、依据、来源，以及已知且有用的适用时间。用 `stated` 表示用户明确陈述，`observed` 表示基于多处行为的观察，`inferred` 表示推断。应将这些依据写在具体条目旁，尤其是条目之间依据不同时；不得把 AI 回答或推断写成用户陈述。未经确认的非敏感推断或冲突应放在待确认区，直至得到解决。用户的更正优先；保留相关变化或未解决的分歧，不声称确定无疑。

链接到真实的来源批次笔记，并在可用时提供定位信息；若来源或定位信息不可用，应如实说明，不得编造。来源笔记应描述来源、允许范围、可用日期、已知的处理时间、定位信息和覆盖限制，不复制对话文本。尽量减少第三方信息，绝不保存密码、密钥或其他凭据。保存摘要而非大量逐字记录；只保留少量必要的简短原句，并注明来源及必要上下文。不得编造原句或将摘要当作精确引用。

## 私密区域与披露

除非当前请求确有必要且用户明确同意具体范围，否则不得读取、搜索、展开、嵌入、引用 `07 Privacy/` 的内容，也不得将其发送给模型。日常搜索、索引、摘要和导出须排除该目录；若工具无法排除，应停止该搜索方式并说明。即使是私密 MOC，也只有在相同授权条件下确需确定私密规则或导航时才可阅读。普通 MOC 只说明边界，不列出私密标题、链接或事实。

保存必要私密材料前，应先获得用户对内容或明确定义的类别及范围的批准，再在 `07 Privacy/` 中保存最少必要内容；未经确认的敏感或第三方私密候选内容不得放入普通待确认区。文件夹、MOC、元数据或这些规则均不提供加密或访问控制。拥有访问权限的工具、插件、索引器和同步服务仍可读取、索引、同步或上传内容。导出、上传、分享或删除前应确认，并检查内容和可识别身份的元数据；外部副本可能无法撤回。
